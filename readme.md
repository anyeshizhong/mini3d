# Usage Method
## 1.py
- Press the WASD keys to control the camera position.
- Press the arrow keys (← → ↑ ↓) to control the camera's yaw, pitch, and roll.
- Press the IJKL keys to control the model, and press Tab to switch the model.

## 2.py
- Press the WASD keys to control the camera position.
- Press the arrow keys (← → ↑ ↓) to control the camera's yaw, pitch, and roll.
- Press the IJKL keys to control the model, press Z and X to control the joints, and press Tab to switch the wheel.
