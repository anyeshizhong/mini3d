# Shadow Mapping V1: complex library assets

Supplement to the initial cube regression, completed before the Issue #4 Rome integration. These tests use actual model-library geometry and original materials.

| Asset | Triangles | Ground shadow pixels |
| --- | ---: | ---: |
| Roman legionnaire | 589879 | 2862 |
| Side Table Tall 01 | 6408 | 5433 |
| WaterBottle | 4510 | 4878 |
| Fox | 576 | 11877 |
| Rome River Side | 353735 | 14672 |

The ground-only depth mask isolates receivers; 12 CPU triangle-ray samples per asset agree with shadow locations. Off/on Camera depth arrays are identical. Roman/table have 1024/2048 comparisons; camera movement preserves the light matrix, while changing the sun changes the result. Fox uses its default static pose; animation is not tested. Rome retains Unlit materials and casts onto an explicit PBR floor. Only entity transforms normalize framing; actual scales and metrics are in [results.json](shadow-assets/results.json).

[Composed Shot](shadow-assets/composed-shot.png) | [Eight soldiers](shadow-assets/eight-soldiers-on.png) | [Table](shadow-assets/side_table-on.png) | [Rome](shadow-assets/rome_river-on.png)

The composed scene exercises table/bottle/soldier, with 79 independently measured bottle-to-table shadow pixels. Shot PNG matches the Camera View render path. Eight soldiers contain 4,719,032 triangles, plus two floor triangles, using seven unique meshes.

Intel UHD 620, 1000x750, seven warmed samples. GPU timer plus renderer.render/glFinish wall time; excludes PNG encoding and ImGui. These are not full Editor FPS measurements.

Reproduce with `F:/gymenv/python.exe -B tests/shadow_assets_smoke.py docs/shadow-assets` and the original local library assets. This adds evidence, not renderer changes. It does not certify every angle, bias setting, animation or material extension.
