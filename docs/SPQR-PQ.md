# SPQR P/Q：天空细节与绘制开销

基于本地 ff4bf55。本轮保持分辨率、抗锯齿、阴影分辨率和几何数量。

- 可见程序天空增加云层细节，以像素导数抑制未能分辨的高频层；低角度云层边缘更细碎。
- 粗糙反射和雾使用平滑大尺度天空近似，省去不可分辨的细云噪声。此方案并非物理预过滤环境图；粗糙材质和雾的颜色会略有变化。清晰反射仍保留云，按模糊量平滑淡出。
- 太阳盘面使用既有 sun_size，并按像素足迹软化边缘；0仍沿用0.53度默认可见直径，HDR天空内烘焙的太阳不受程序盘面控制。
- 月面噪声只在可见月盘内计算，星空/月夜照片与基线相同。
- 同一材质绘制pass内复用相同贴图/采样状态；每次pass开始重新验证绑定，避免跨pass错误复用。贴图初始化仍在正确纹理单元执行。

新增GPU验证：`python -B tests/spqr_sky_quality_smoke.py --output captures/sky-quality`。
太阳从0.53度调到2度时，测试机位亮盘面积由188增至2340像素；GL错误0。
完整性能和图像对照采用已有spqr_performance_benchmark、spqr_editor_performance和spqr_performance_smoke脚本，以修改前源码快照为基线。天空本身预期改变颜色，不能要求与旧天空逐像素相同；只验证贴图状态优化时，参考必须使用相同天空shader。

不含建筑纹理重制、LOD、GI或新的云体积系统。此轮代码保留待用户验收，不自动提交。
