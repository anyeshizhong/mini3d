# 本机测试输出

本目录继续被 Git 忽略；只有本说明显式登记。生成结果与原件的角色不同，不能因图片相似或远端已有图片删除本机原件。

| 类别 | 保存要求 |
| --- | --- |
| 正式发布/回归结果 | 保留 runs.json、日志、参数、资产 SHA、原图对照；作为该次执行的独立证据 |
| Q1/Q2、Blender、Rome、失败前后证据及独有摄影 | 原图/Scene/模型输入/许可按原位保留；新实测写新目录 |
| 可再生输出 | 对应脚本、提交、原始资产与环境齐全才可认定可再生；本轮未删除原有输出 |
| 下载与生成 Fixture | 原始下载模型与许可证区别于几何 Fixture；固定 SHA、来源和生成命令随结果保留 |

新运行使用 `captures/<新的实验名>/`，统一执行器会拒绝已存在的输出目录。不要把测试输出写入 docs 的历史原图目录。新的研究采集程序要求显式新输出目录。性能 raw samples、阴影运动 trace/depth 和场景 JSON 都有解释照片的价值，不能只留缩略图。

本轮完整本机 SHA 清单、内容相同组与分类保存在忽略的 `archives/v2-test-engineering-20261011/`，未上传私人文件清单。相同字节仍可能是不同执行、对照或预览/导出一致性的证据；本轮不进行照片去重。
