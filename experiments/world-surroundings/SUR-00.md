# SUR-00 · 摄影视野与外围表示对照

2026-10-20：**SUR-00固定原型、首轮实测与回归完成，C三维地理作为继续开发主线；完整世界、摄影画质和性能未通过。** 本阶段实现固定罗马郊外示例、确定性摄影路线和最小 A/B/C 实验，用于选择外围表示与发现架构风险。自由摄影窗口和正式编辑器集成尚未实现。总体设计见 [SURROUNDINGS.md](SURROUNDINGS.md)，任务看板见 [PROJECT.md](../../PROJECT.md)，原图和全部逐帧数据见 [审阅入口](review/sur00-20261020/README.md)。

## 输入与复现

在仓库根目录的 Windows 桌面 GL 会话运行，依赖沿用 [README](README.md)：

```powershell
F:/gymenv/python.exe -B experiments/world-surroundings/run_surroundings.py --output captures/world-surroundings/sur00-reproduce --conditions day-clear day-haze day-haze-strong sunset-haze
```

输出必须为新目录或空目录。构建使用 `captures/world-surroundings/build-sur00` 中的隔离 `terrain_lab.dll`，不替换生产 DLL。`--visible` 仅显示相机回放窗口，不提供手动飞行。快速检查可用 `--samples 24 --warmup 4 --repeats 1 --conditions day-haze --skip-sweep --skip-recordings`，其测量不能混入正式基线。

B背景立方体的角点比面中心更远；包含B时要求`--far >= 6000`，防止短far悄悄裁掉二维对照。2/4km专项诊断可用`--variants A C`，内置镜头扫参本来就只测C。8km是本轮诊断输入，不是生产默认裁剪距离。

场景固定种子 24037、Z-up、米制，城市台地 Z=100m；复用原创 Roman Street 和六栋外围房屋。共同地表范围为 X/Y 各 ±9km，使用整张连续、静态变密度网格，中央步长8m，外层24/64/128m。这不是动态 LOD，也尚未完成空间分块。南侧谷地与1.8km静态贴地道路确定出口方向；北侧山脊由五个有序控制点确定，不做环形随机山墙。

所有方案共用城市、道路、共同地表、相机帧、曝光、天空、太阳和阴影设置：

| 方案 | 唯一的表示差异 | 边界 |
| --- | --- | --- |
| A | 共同地表与城市，只有既有天空 | 作为无远山的基线，保留共同地面 |
| B | C远山在固定世界锚点烘焙的六面RGB与轮廓mask，放到半径3km的固定背景立方体 | 每个光照/Haze批次重新准备，不支持动态光照；非多视角Impostor系统 |
| C | 世界坐标中的真实三维山脊，使用既有SPQR PBR/遮挡/阴影 | 当前为单色低成本几何，未达到自然地表摄影质量 |

B不重复施加曝光、光照或Haze；天空透明区域discard，保留固定轮廓。B的固定立方体仍有几何视差，但它对应3km背景面，不能等同于约0.8～1.2km主山脊的真实视差。仅本fixture借AO纹理槽识别背景，普通材质不得有AO贴图；不构成通用背景材质协议。山脚与共同地表同源，移除了完全共面的山体三角形并压缩引用顶点，避免矩形底板重叠。没有新增第三方模型、照片、纹理或引擎算法代码；Roman Assets来自仓库原创，天空/中性IBL沿用既有 [NOTICE](../../mini3d/resources/ibl/NOTICE.md)。

## 摄影与测量口径

目标摄影区域为 X/Y 各 ±200m、地表上1.6～120m。本阶段21个固定机位覆盖街道、出口/回望、120m高空、垂直向下、四边四角、向外地平线、35°/52°/75°及长焦；六条120帧路线覆盖出城、横移、升降、环绕、高/低边缘巡检。它们是离散探测与回放，不等于所有位置/俯仰均已通过。

长焦由85mm焦距与24mm传感器高度换算垂直FOV约16.07°；保留原1081:662输出比例，水平FOV由窗口比例决定，并非36:24画幅的原比例成像。元数据同时保留名义36×24mm参考和真实投影矩阵。

白天Haze=0/0.0001/0.0003与夕阳Haze=0.0001分批捕获；性能只测白天0.0001，其他光照不重报性能。1081×662、1x AA、远阴影1024、稳定近阴影4096、vsync关闭。每项预热24帧、120帧采样、三轮轮换A/B/C顺序；静止及六条路线分别保留全部360个样本，不删慢帧。完整原型帧包含事件读取、native render+glFinish和swap，不含读回/图片编码；不是Editor帧率，也不是纯GPU timestamp。

动态PNG/GIF是额外回放，GIF按固定模拟时间播放，不代表墙钟帧率。原PNG只进行无损格式转换，没有调色/重绘。代表机位保存原生捕获矩阵和远阴影float深度；其余机位保存RGB、相机与即时统计。`.depth.f32`是远阴影图，不是相机深度图，也不能证明近阴影像素质量。

真实PNG抽查覆盖街道/高空、出口、向外地平线、垂直俯视、长焦、夕阳及横移样本。C保留三维位置与前景遮挡，B在高空、横移时具有错误深度的视差和较粗轮廓；当前C仍有明显单色“山墙”感、平缓区域空旷、地平线生硬，未达到自然摄影世界。全部机位及样本数据开放审阅，未把抽查解释为任意位置视觉通过。

## 当前发现与下一阶段

本轮不把Shader编译、几何覆盖或脚本完成标记解释为完整世界通过。主要待解决项是：

1. 大块普通地表进入阴影拟合，近阴影深度跨度达到十多公里；A已存在共同成本，C的相对开销不能掩盖它。现有`fit_stable_shadow`会扫描所有非ground投影者，单纯分块还不够，须明确近/远caster参与和局部拟合范围。SUR-01先修复这一问题、保留城市近阴影并做相同机位回归，再扩建外围，不能把它当作最后的性能优化。
2. 关闭Haze时地平线仍生硬；±9km地表不是按所有75°视锥朝向证明过的覆盖上界，不能据此承诺全范围无边缘。按相机范围、俯仰/FOV和far推导支撑范围，并补连续向外巡检。
3. 当前山脊有方向性，但色彩单一、坡面平滑，仍像技术模型；南侧空间空旷，静态道路有有限终点。SUR-02再加入田块、树林、少量农庄及可信土地过渡，不把它们提前标为完成。
4. 原型查询与网格共用精确三角面。道路除顶点贴地外，补充每三角形66点、全路29,700点的内部采样：相对地面净空约1.85～3.22cm，摄影区域内约1.99～2.56cm，未发现穿地；这是固定示例的采样检查，不是任意曲路的连续误差证明。完整Spline、道路控制历史和通用挖填继续后置。
5. 当前统计覆盖实验显式网格/纹理更新与Shader编译，不覆盖Renderer内部实例缓冲上传。没有外围颜色/阴影专用GPU区段计时、驱动显存或CPU峰值缓存测量；纹理估算也不包括FBO/阴影/驱动开销。

SUR-01、SUR-02、SUR-03与SUR-PERF仍分别验收。C是继续开发主线；B保留为本固定锚点对照，不用它的限制否定所有远景Impostor。后续不能靠加浓雾、缩小摄影范围或关闭城市阴影掩盖问题。
